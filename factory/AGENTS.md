# Factory kit

This folder is the method. The always-on brief for the repo is
[`../AGENTS.md`](../AGENTS.md), generated from [`config.yaml`](config.yaml)
by `python3 factory/cli.py install`.

When the work is research, design, tickets, implementation, review, tests,
comments, or an assessment, read
[`skills/factory-router/SKILL.md`](skills/factory-router/SKILL.md) and follow
one row. Do not load every file under [`policy/`](policy/).
