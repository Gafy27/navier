# Skill bindings (TypeScript stack)

This pack has no bundled language skills or required default skill.
Read [`code-style.md`](code-style.md) for its language rules. Host skills
(TypeScript, Node, framework-specific skills) are mapped by the adopting
repo's `<paths.profile>/skills.md`; load only those the task touches, using
the entrypoint paths provided there.

Secure-code, naming, and testing skills remain in the kit's `skills/`
folder and follow `policy/implementation.md` and `policy/testing.md`.
