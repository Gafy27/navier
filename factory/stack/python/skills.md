# Skill bindings (Python stack)

Skill directories below are relative to this pack's `skills/`; open their
`SKILL.md` entrypoints, then only the supporting references the task needs.
There is no required default; load skills by task. Product-specific bindings
stay in the adopting repo's `<paths.profile>/skills.md`.

| Skill | Use when |
|-------|----------|
| `python-patterns/` | Python idioms, typing, error handling |
| `python-code-style/` | Writing or reviewing style, linting, docstrings |
| `python-pro/` | Advanced Python, async, type-system or standard-library questions |
| `python-testing-patterns/` | pytest, fixtures, mocks, test organization |
| `python-performance-optimization/` | Profiling or fixing measured performance problems |
| `python-configuration/` | Environment configuration and typed settings |
| `python-project-structure/` | Package layout and module boundaries |
| `python-packaging/` | Building and distributing packages |
| `python-poetry/` | Poetry dependencies and environments |

Secure-code, naming, and testing skills remain in the kit's `skills/`
folder and follow `policy/implementation.md` and `policy/testing.md`.
